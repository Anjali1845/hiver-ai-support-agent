# Spotify AI Support Agent

An AI-powered customer support agent built on the Customer Support on Twitter dataset for the Hiver SDE Internship assignment.

## Features
- Intent classification
- AI reply generation
- Human escalation prediction
- Golden evaluation dataset

## Tech Stack
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## Dataset
Uses the Kaggle Customer Support on Twitter dataset.
The raw dataset is excluded from this repository via `.gitignore`.
